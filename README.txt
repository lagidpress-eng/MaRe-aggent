MAKE READY AGENT V1 — STANDALONE

Без Google Apps Script и без Google API.

Бесплатный запуск на Netlify:
1. Открой https://app.netlify.com/drop
2. Распакуй ZIP.
3. Перетащи папку Make_Ready_Agent_V1_Standalone на Netlify Drop.
4. Открой полученную .netlify.app ссылку на телефоне.
5. Разреши GPS.
6. На iPhone: Share -> Add to Home Screen.

Важно:
- Данные сохраняются локально в браузере.
- Фото BEFORE/AFTER сохраняются локально в IndexedDB.
- Export Production CSV выгружает таблицу выполненных работ.
- Backup JSON сохраняет рабочие данные и список фото, но не сами изображения.
- Не очищай данные Safari/Chrome до резервной копии.
